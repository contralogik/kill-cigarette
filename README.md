# Kill Cigarette · 先停一会儿

一个手机优先的戒烟自我记录与应对练习工具。可直接托管到 GitHub Pages，无需构建或服务端。

- 想抽时立即进入练习：慢呼吸、离开工位、回到当下、手部放松、写最小下一步。
- 一键记一根，调整数量、补充触发场景、撤销；复抽后保留此前进展。
- 可选的前后烟瘾评分、应对结果和后续自报，不自动判定练习成功。
- 只对已结束且确认过总根数的日期计算无烟日和估算节省；缺失记录保持未知。
- 兼容原来 `smoking.html` 和旧版 `kc_singlefile_v1` 数据；保留旧版原始 key 供恢复。
- 12 张生成水彩场景、1 张呼吸素材、42 句原创短句；语气可选、动画可关闭。
- “我的激励”保留用户提供的 5 张原图，支持切换、从救急练习打开并返回原计时。
- JSON 导入导出、离线基础页面及已查看插图缓存；个人记录仅保存在当前浏览器。

入口：[线上应用](https://contralogik.github.io/kill-cigarette/smoking.html)

## 本地开发

```sh
npm install
npm run dev
npm test
npm run check
npm run test:e2e
```

浏览器测试使用独立的 Playwright Chromium 环境，不连接用户浏览器数据。生成插图的提示词与资产映射见 `assets/art/README.md`。

首次运行浏览器测试前可执行 `npx playwright install chromium --only-shell`。已有独立的 Chromium 测试程序时，可通过 `KC_TEST_BROWSER` 指定它的可执行文件路径。

## 数据说明

新版 key 为 `kc_support_v2`。首次加载会迁移旧版汇总、现存明细、图片和文案，不将旧版缺失日期视为无烟，也不把汇总和同一天旧明细重复相加。损坏的原始数据会保护起来并提供下载，不会自动覆盖。

导入在验证文件后才要求确认替换；有现存记录时会先下载一份替换前备份。没有账号同步，请定期导出并妥善保管备份中的个人信息。

本工具提供自我记录和应对练习。健康信息依据 WHO 与 Smokefree，来源在应用内帮助页；药物及临床支持由医生评估。
